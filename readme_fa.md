## 🚀 نصب سریع (مخصوص لینوکس)

برای نصب و راه‌اندازی سریع ربات بر روی سرور لینوکسی خود، دستور زیر را در ترمینال وارد کنید. این دستور، پروژه را دانلود کرده و اسکریپت نصب خودکار را اجرا می‌کند. در طی فرآیند نصب، از شما خواسته می‌شود **توکن ربات تلگرام** و **آیدی عددی اکانت ادمین(ها)** را وارد نمایید.

```bash
git clone https://github.com/YOUR_USERNAME/telegram-downloader-bot.git && cd telegram-downloader-bot && chmod +x install.sh && ./install.sh
```
**توجه:** لطفاً `YOUR_USERNAME` را با نام کاربری صحیح خود در گیت‌هاب (یا آدرس کامل ریپازیتوری اگر فورک کرده‌اید) جایگزین کنید.

اسکریپت `install.sh` مراحل زیر را انجام می‌دهد:
*   بررسی پیش‌نیازهای سیستم.
*   ایجاد محیط مجازی پایتون.
*   نصب کتابخانه‌های مورد نیاز.
*   دریافت توکن ربات و آیدی ادمین از شما و ذخیره آن‌ها در فایل `.env`.
*   ایجاد پوشه‌های ضروری.
*   ارائه گزینه‌هایی برای نصب ربات به عنوان سرویس systemd (برای اجرای خودکار و دائمی) و تنظیم وظایف cron برای مانیتورینگ و بکاپ.

### سایر روش‌های نصب و اطلاعات تکمیلی

برای کاربرانی که مایل به انجام نصب به صورت مرحله به مرحله دستی هستند، یا از سیستم‌عامل‌های دیگری استفاده می‌کنند، و همچنین برای مشاهده جزئیات کامل پیکربندی، راه‌اندازی سرویس، و سایر موارد پیشرفته، لطفاً به مستندات کامل نصب در فایل [INSTALL.md](INSTALL.md) (نسخه انگلیسی) یا [INSTALL.fa.md](INSTALL.fa.md) (نسخه فارسی) مراجعه فرمایید.

## 🔧 پیکربندی

### متغیرهای محیطی

فایل `.env` در ریشه پروژه ایجاد کنید:

```env
# تنظیمات ربات
BOT_TOKEN=توکن_ربات_شما
ADMIN_IDS=123456789,987654321

# تنظیمات اختیاری
MAX_FILE_SIZE=2147483648  # 2GB به بایت
DEFAULT_DAILY_LIMIT=10
DOWNLOAD_TIMEOUT=3600
```

### دریافت توکن ربات

1. در تلگرام به [@BotFather](https://t.me/botfather) پیام دهید
2. دستور `/newbot` را ارسال کنید
3. نامی برای ربات انتخاب کنید
4. یوزرنیم انتخاب کنید (باید به 'bot' ختم شود)
5. توکن ارائه شده را کپی کنید

### دریافت آیدی تلگرام

1. در تلگرام به [@userinfobot](https://t.me/userinfobot) پیام دهید
2. هر پیامی ارسال کنید
3. آیدی عددی خود را کپی کنید

## 📱 استفاده

### برای کاربران

1. **شروع ربات**
   ```
   /start - راه‌اندازی ربات و مشاهده وضعیت
   ```

2. **دانلود فایل**
   - لینک مستقیم دانلود را ارسال کنید
   - فرمت ارسال را انتخاب کنید
   - فایل را دریافت کنید

3. **مشاهده آمار**
   ```
   /mystats - نمایش آمار دانلود شما
   ```

4. **دانلود با کد**
   ```
   /dl CODE - دانلود فایل با کد ارائه شده توسط ادمین
   ```

### برای ادمین‌ها

1. **دسترسی به پنل ادمین**
   ```
   /admin - باز کردن پنل کنترل ادمین
   ```

2. **امکانات ادمین**:
   - 📊 مشاهده آمار سیستم
   - 📈 تولید نمودار فعالیت
   - 👥 مدیریت کاربران (VIP، بن، محدودیت)
   - ⚙️ پیکربندی تنظیمات سیستم
   - 📤 آپلود فایل با کد یونیک
   - 🗑️ پاکسازی فایل‌های قدیمی
   - 📢 ارسال پیام همگانی
